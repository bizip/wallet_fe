# Wallet Platform

> A web application designed to help individuals manage their financial transactions effectively by tracking incomes and expenses across multiple accounts. With this app, users can set budgets, categorize spending, and visualize transaction summaries, making personal finance management seamless and intuitive

## Link to live version

#[Click here to view the hosted version](https://phenomenal-heliotrope-c63358.netlify.app)

## Built With (it has 2 repositories wallet_fe and wallet_be)

-Node Js, React, firebase and tailwind css

## Getting Started

To get a local copy up and running follow these simple example steps.

### Prerequisites

You need to have a git and node installed
You need to have a basic knowledge about how to use terminal and to create firebase project

### Setup

#### clone this project (using git clone https://github.com/bizip/wallet_fe.git and git clone https://github.com/bizip/wallet_be.git) to your local computer and use telminal to navigate into the parent directory of this project.

### Install

#### CONFIGURE FIREBASE .ENV CREDENTIALS
#### Run npm install

### Usage

run: npm run dev and npm start for frontend
